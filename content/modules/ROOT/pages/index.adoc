= Four ways your agent can break

== Lab overview

Build a field service agent for Kestrel Industrial, a fictional chiller manufacturer, one layer at a time. Diagnose each failure from the request and response payloads or execution trace, apply the fix, and check the evidence again.

These pages mirror the seven Jupyter notebooks, with their explanations, questions, diagrams and code cells in order. You can review the lab here without provisioning an environment. To execute the cells, open the corresponding notebook in the lab's JupyterLab workbench.

The notebook wording is a working draft. These pages show code without executing it and omit saved outputs. Evidence tables, model responses and links to a particular environment appear when the notebook runs; descriptions of those results state what to inspect during the lab.
