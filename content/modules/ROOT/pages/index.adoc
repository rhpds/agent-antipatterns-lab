= Four ways your agent can break

== Lab overview

You'll build a field service agent for Kestrel Industrial, a fictional maker of industrial cooling equipment. The agent helps service engineers find parts, check stock and delivery times, and look up service bulletins.

The agent you start with has problems that don't show up as errors. Module 1 shows you how to see inside it. In the modules after that, you find what's wrong from the evidence: the request sent to the model, the response that came back, what a tool returned, and the trace in MLflow. Then you apply the fix and check the evidence again.

== What's running in your lab

Everything runs on one OpenShift cluster with Red Hat OpenShift AI. Your workbench and database are in your own project. The model endpoints, MLflow and the tool gateway are shared by everyone in the session.

== How to work through the lab

Each module has a Jupyter notebook in your workbench. Open the *Notebook* tab on the right, where module 1's notebook opens. Run the cells in order and answer the questions as you go. Each page on this side is a short guide to its module: what it covers, its steps, how you know it worked and, where the module has them, questions to think about. The code and its results are in the notebook.

To start a module over, open a terminal in the workbench (*File > New > Terminal*), go to the `agent-antipatterns-lab` folder and run `python agent/reset.py <module number>`. Your edits are saved before the reset.
