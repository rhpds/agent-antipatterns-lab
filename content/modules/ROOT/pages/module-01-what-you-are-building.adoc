== 1. Meet the agent

The agent answers field service questions for Kestrel Industrial (a fictional chiller maker). Three files matter: link:{lab-source-url}/agent/tools.py[`+tools.py+`] (the tools the model is offered), link:{lab-source-url}/agent/agent.py[`+agent.py+`] (the loop) and link:{lab-source-url}/agent/config.toml[`+config.toml+`] (which model endpoint it calls). Each run leaves two kinds of evidence: the raw payloads under `+agent/runs/+`, and a trace in MLflow.

== 4. Your first trace

MLflow keeps one *trace* per run. A trace is a tree of *spans*, one per step:

* `+agent_run+` is the whole run. Its outputs say how the run ended and how many tools it called.
* `+model_call_1+` is one request to the model. Its *Inputs* hold the messages and the tools offered; its *Outputs* hold `+finish_reason+`, `+tool_calls+` and `+content+`.
* A tool the agent actually runs gets its own span underneath. This run should have none.

Open the trace and click each span. Compare what it shows with the payload above.
