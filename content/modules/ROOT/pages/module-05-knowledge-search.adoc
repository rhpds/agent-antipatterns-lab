== Learning objectives

* Integrate a searchable knowledge source so the agent grounds its answers in retrieved content rather than in model memory.
* Verify that a retrieval miss produces an explicit gap rather than an invented answer.

== The confident invention (3 min)

. Ask about the coolant pump seal. The answer exists only in service bulletin SB-2024-117.
+
[source,bash,role=execute]
----
python agent.py --q m5
----
. Note the specific, plausible, wrong answer. Module 4 does not catch it, because no tool failed.
. Confirm in the trace that no retrieval happened.

== Register the retrieval tool (5 min)

. Query the pre-populated corpus directly, outside the agent:
+
[source,bash,role=execute]
----
python retrieval.py "coolant pump seal service interval"
----
. Note each passage carries its source identifier, which is what makes an answer checkable.
. Register the supplied `search_bulletins` tool:
+
[source,bash,role=execute]
----
cp solutions/module-05/tools.py solutions/module-05/agent.py .
----
. Read the declaration, its parameters, and its return shape, which uses module 4's contract.
