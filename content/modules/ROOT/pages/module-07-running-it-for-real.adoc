== 3. The baseline

`+name="my-baseline"+` recorded this run in MLflow as an *evaluation run*: one row per case, each with its trace and the same PASS, FAIL or SKIP and reason printed above. Nothing judges the wording; the verdicts are the regression set's own checks. The run also keeps the `+passed+`, `+failed+` and `+skipped+` counts, and it is linked to the agent version that produced it, for example `+kestrel-m7-start+`, or `+kestrel-m7-start-modified+` once you've edited the agent.

To compare a later run with this baseline, run the set again under another name, then open the experiment's *Evaluation runs* tab and select both runs. Each case's two results sit side by side, and the cases that changed stand out:

[source,python]
----
lab.links(("The experiment's Evaluation runs tab", lab.experiment_url("evaluation-runs")))
----

This baseline is evidence that today's build handles the failures it was built for, and no evidence at all about failures nobody has thought of yet. The checklist at the end of the report maps each symptom a customer might describe to the layer to look at first; take it with you.

Two failure modes this lab covered only by discussion: a model or prompt change underneath a working agent, and cost under real concurrency.
